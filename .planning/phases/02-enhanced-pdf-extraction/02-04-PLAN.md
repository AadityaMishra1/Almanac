    A client component that renders the extraction preview with inline editing. Do NOT use TanStack Table - keep it simple with the existing Radix UI Table components (already in components/ui/table.tsx) to stay consistent with the codebase.     ```
    "use client";

    Type for row:
    import type { EventWithConfidence } from "@/lib/events/types";

    type PreviewRow = EventWithConfidence & { selected: boolean; id?: string };

      rows: PreviewRow[];
      onChange: (rows: PreviewRow[]) => void;
    }

    Columns:
    1. **Sync checkbox** - Checkbox using existing Radix Checkbox component. Pre-selected for high confidence, deselected for low confidence (< 0.6).

    Row styling:
    - Rows with confidence < 0.6: add subtle red/amber left border or light background tint (e.g., `bg-red-50/50`) to draw attention
    - Normal rows: default white background

    `updateRow` function: same pattern as existing EventsTable - create new array with updated row at index, call onChange.

    Use existing UI primitives from components/ui/ (Table, TableBody, TableCell, TableHead, TableHeader, TableRow, Checkbox, Input).
