  <action>
    **Step 1: Create lib/pdf/extract-tables.ts**

    Export `extractTables(buffer: Buffer): Promise<string>`.

    Implementation:
    - Import pdf-parse using the same internal import pattern as extract-text.ts: `await import("pdf-parse/lib/pdf-parse")`
    - Extract text from the PDF and look for table-like structures
    - Use a heuristic approach: look for lines with multiple tab/pipe-separated columns, or consistent spacing patterns that indicate tabular data
    - For each detected table-like section, format as pipe-separated rows for LLM readability
    - Return the formatted table text, or empty string if no tables detected

    Table detection heuristic:
    - Split text into lines
    - Lines with 3+ tab characters OR 3+ pipe characters are likely table rows
    - Lines with consistent multi-space gaps (4+ spaces between words) may be column-aligned
    - Group consecutive table-like lines as a single table
    - Format output as: `| col1 | col2 | col3 |` rows for LLM clarity

    Note: This is a simple heuristic approach for Phase 2. More sophisticated table extraction (using pdf-parse's getTable or tabula-js) can be added in Phase 3 if needed. The key insight from research is that feeding table-formatted text to the LLM yields better event extraction than raw whitespace-separated text.

    **Step 2: Update lib/pdf/index.ts**

    Add table extraction to the `ExtractionResult` interface and `extractPdfContent` function:

    ```typescript

      text: string;
      tables: string;  // NEW: formatted table data

        method: 'text' | 'ocr';
        pageCount: number;
        hasTableData: boolean;  // NEW: whether tables were detected
      };
    }
    ```

    In `extractPdfContent()`:
    - After text extraction (either text or OCR), call `extractTables(buffer)` on the original buffer
    - Include table results in the return value
    - Set `hasTableData: tables.length > 0`
