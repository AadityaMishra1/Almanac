  <action>
    **Step 1: Install dependencies**

    Run: `npm install tesseract.js pdf.js-dist canvas date-fns`

    Note: `canvas` is required by pdf.js-dist for server-side rendering of PDF pages to images. `date-fns` will be used in Plan 02 for date validation but install now to avoid duplicate installs.

    **Step 2: Create lib/pdf/extract-text.ts**

    Wrap the existing `parseSyllabusPdfToText()` from `lib/pdf.ts` into this new file. Keep the same internal import pattern (`pdf-parse/lib/pdf-parse`) that avoids the debug test file loader issue in Next.js. Export as `extractTextFromPdf(buffer: Buffer): Promise<string>`.

    **Step 3: Create lib/pdf/detect-pdf-type.ts**

    Export `detectPdfType(buffer: Buffer): Promise<'text' | 'scanned'>`.

    Implementation:
    - Use pdf-parse to extract text from buffer (same import pattern as extract-text.ts)
    - Calculate `charsPerPage = text.length / numpages`
    - If `charsPerPage < 100`, return `'scanned'`
    - Additional check: `text.split(/\s+/).length > (numpages * 50)` for word density
    - Return `'text'` if both checks pass, `'scanned'` otherwise

    **Step 4: Create lib/pdf/extract-ocr.ts**

    Export `extractTextViaOCR(buffer: Buffer): Promise<string>`.

    Implementation following research Pattern 2:
    - Import `getDocument` from `pdfjs-dist/legacy/build/pdf.mjs` (legacy build for Node.js compatibility)
    - Import `createWorker` from `tesseract.js`
    - Import `createCanvas` from `canvas`
    - Load PDF with `getDocument({ data: buffer }).promise`
    - Initialize Tesseract worker: `await createWorker('eng')`
    - Process pages SEQUENTIALLY (not parallel) to avoid memory issues:
      - Get page viewport at scale 2.0 (quality)
      - Create canvas at viewport dimensions
      - Render page to canvas context
      - Run `worker.recognize(canvas.toBuffer('image/png'))`
      - Push text to results array
      - Set canvas reference to null for GC
    - Terminate worker after all pages: `await worker.terminate()`
    - Return joined page texts with `\n\n` separator

    Important: Wrap in try/finally to ensure worker.terminate() always runs even on error.

    **Step 5: Create lib/pdf/index.ts**

    Export unified interface:

    ```typescript
    export interface ExtractionResult {
      text: string;
      metadata: {
        method: 'text' | 'ocr';
        pageCount: number;
      };
    }

    export async function extractPdfContent(buffer: Buffer): Promise<ExtractionResult>
    ```

    Implementation:
    - Call `detectPdfType(buffer)` to determine extraction method
    - If `'text'`: use `extractTextFromPdf(buffer)`
    - If `'scanned'`: use `extractTextViaOCR(buffer)`
    - Get page count from pdf-parse for metadata
    - Return `{ text, metadata: { method, pageCount } }`

    **Step 6: Keep lib/pdf.ts as backward-compatible re-export**

    Do NOT delete `lib/pdf.ts`. Instead, update it to re-export from the new module:
    ```typescript
    export { extractTextFromPdf as parseSyllabusPdfToText } from './pdf/extract-text';
    ```
    This ensures `app/api/parse/route.ts` continues to work without changes in this plan. Plan 03 will update the route to use the unified interface.
