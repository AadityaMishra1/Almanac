  <action>
**Add delete to EventDetailModal:**

In the existing `event-detail-modal.tsx`, add a delete button in view mode (alongside the existing Edit and Close buttons). Only show for editable (ALMANAC) events.

**Two-step delete pattern (from CONTEXT.md):**
1. Add `deleteState` to component state: `'idle' | 'armed' | 'deleting'`
2. First click on Delete button: set state to `'armed'`, change button to red with text "Click again to delete" (or "Confirm Delete")
3. Second click: set state to `'deleting'`, execute deletion
4. If user clicks elsewhere or closes modal: reset to `'idle'`
5. Auto-reset armed state after 3 seconds (setTimeout) — prevents accidentally leaving it armed

**Delete button styling:**
- idle state: `variant="outline"` with red text (`text-red-600 hover:text-red-700 hover:bg-red-50`)
- armed state: red background (`bg-red-600 text-white hover:bg-red-700`), text changes to "Confirm Delete"
- deleting state: show Loader2 spinner, disabled

**Deletion logic:**
1. Call `deleteEvent(event.id)` server action (already exists in events.ts)
2. If event has a `googleEventId` (was synced to Google Calendar), also call new `deleteGoogleCalendarEvent(googleEventId)` server action
3. On success: call `router.refresh()`, close modal, call `onEventDeleted` callback
4. On error: show error message, reset delete state

**Add `onEventDeleted` callback prop** to EventDetailModal (alongside existing onEventUpdated). CalendarView should handle this by closing the modal.

**Add `deleteGoogleCalendarEvent` server action** to `app/server-actions/calendar.ts`:
- Get session access token (same pattern as syncEventsToCalendar)
- Call `calendar.events.delete({ calendarId: 'primary', eventId: googleEventId })`
- Return `{ ok: true }` or `{ ok: false, error: string }`
- If Google API fails (event already deleted, token expired), still allow local deletion (warn but don't block)

**Also needed:** Pass `googleEventId` through the CalendarEvent type so the modal knows if the event was synced. Add `googleEventId?: string` to the CalendarEvent interface in both `calendar-view.tsx` and `event-detail-modal.tsx`. Populate from Prisma event data in `prismaEventToCalendarEvent`.
