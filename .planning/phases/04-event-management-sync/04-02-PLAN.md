  <action>
Create the sync engine as a modular library under `lib/sync/`.

**`lib/sync/fetch-google-events.ts` — Fetch from Google Calendar:**
- Export `fetchGoogleEvents(accessToken: string, options?: { timeMin?: string; timeMax?: string })`
- Use `getCalendarClient(accessToken)` from `@/lib/google`
- Call `calendar.events.list({ calendarId: 'primary', timeMin, timeMax, singleEvents: true, orderBy: 'startTime', maxResults: 250 })`
- Default timeMin: 6 months ago. Default timeMax: 6 months from now.
- Convert each Google Calendar event to local format:
  ```typescript
  interface GoogleEventData {
    googleEventId: string;
    title: string;
    date: string; // YYYY-MM-DD from start.date or start.dateTime
    time: string | null; // HH:MM from start.dateTime, null for all-day
    type: string; // default "other" for external events
    description: string;
  }
  ```
- Handle both all-day events (`start.date`) and timed events (`start.dateTime`)
- Parse dateTime to extract date and time components
- Return `GoogleEventData[]`

**`lib/sync/push-events.ts` — Push Almanac events to Google:**
- Export `pushEventsToGoogle(accessToken: string, events: Event[])` where Event is Prisma type
- Filter to only ALMANAC source events that have no googleEventId (not yet synced)
- For each unsynced event: insert to Google Calendar (reuse existing pattern from syncEventsToCalendar)
- Update local event with returned googleEventId
- Return `{ pushed: number; errors: string[] }`
- Use `getCalendarClient` from `@/lib/google`

**`lib/sync/sync-engine.ts` — Orchestrate bidirectional sync:**
- Export `runSync(accessToken: string)` returning `SyncResult`:
  ```typescript
  interface SyncResult {
    ok: boolean;
    fetched: number; // Google events imported
    pushed: number; // Almanac events pushed to Google
    skippedDuplicates: number;
    errors: string[];
  }
  ```
- Steps:
  1. **Fetch from Google:** Call `fetchGoogleEvents(accessToken)`
  2. **Deduplicate imports:** For each fetched event, check if `googleEventId` already exists in local database (via `prisma.event.findUnique({ where: { googleEventId } })`). Skip if exists (increment skippedDuplicates).
  3. **Import new external events:** For events not in local DB, need a course to associate. Create/get a "Google Calendar" catch-all course via `getOrCreateCourse({ code: 'GCAL', name: 'Google Calendar', semester: 'External' })`. Create event with `source: GOOGLE_CALENDAR`, `editable: false`.
  4. **Push Almanac events to Google:** Call `pushEventsToGoogle(accessToken, localAlmanacEvents)` for events without googleEventId
  5. Return SyncResult

**`app/server-actions/calendar.ts` — Add syncCalendar server action:**
- Add `syncCalendar()` server action alongside existing `syncEventsToCalendar`
- Get session and access token (same pattern)
- Call `runSync(accessToken)`
- Return SyncResult to client
- Add smart throttling: check last sync time, if < 10 seconds ago return early with message "Synced recently. Try again in X seconds." Store last sync time in a module-level variable (per-request is fine since server actions are stateless, but add a header/cookie approach or just let it be per-deploy).

**Important considerations:**
- The existing `syncEventsToCalendar(eventIds)` function should remain for the PDF upload flow (sync selected events). The new `syncCalendar()` does the full bidirectional sync.
- Use try/catch around each individual event to prevent one failure from blocking all. Collect errors in array.
- Handle Google API pagination if `nextPageToken` exists in response.

**Create `components/calendar/sync-status-indicator.tsx`:**

A small status badge component for the calendar toolbar showing sync state.

Props: `{ status: 'idle' | 'syncing' | 'done' | 'error'; lastSyncResult?: SyncResult; onSync: () => void }`

**Visual states (from CONTEXT.md: "small icon/badge that animates during sync, subtle and always visible"):**
- `idle`: Cloud icon (lucide-react `Cloud`) in zinc-400, clickable to trigger sync. Tooltip: "Click to sync"
- `syncing`: Cloud icon with animated spin/pulse (`animate-pulse`), text "Syncing..." in zinc-500. Non-clickable.
- `done`: Cloud check icon (`CloudCheck` or `CheckCircle2`) in green-500, fades to zinc-400 after 3 seconds. Tooltip: "Synced — {fetched} imported, {pushed} pushed"
- `error`: Cloud alert icon (`CloudAlert` or `AlertCircle`) in red-500. Tooltip: error message.

**Expandable details (from CONTEXT.md: "default to simple status, user can click to see full summary"):**
- Click on the indicator when in `done` state opens a small popover (use Radix Popover or just a positioned div) showing:
  - "Events imported: {fetched}"
  - "Events pushed: {pushed}"
  - "Duplicates skipped: {skippedDuplicates}"
  - If errors: list of error messages in red
- Keep it simple — no new Radix dependency if possible. A small positioned dropdown with `absolute` positioning works.

**Toolbar integration:**
- In `CalendarToolbar`, add the SyncStatusIndicator to the right side of the toolbar (between date label and view toggles on desktop, in second row on mobile)
- Pass sync state props down from CalendarView

**CalendarView integration:**
- Add sync state management: `syncStatus`, `lastSyncResult` state
- Create `handleSync` function that:
  1. Sets status to 'syncing'
  2. Calls `syncCalendar()` server action
  3. On success: sets status to 'done' with result, calls `router.refresh()` to refetch events
  4. On error: sets status to 'error'
  5. Auto-reset to 'idle' after 5 seconds for 'done' state
- Pass handleSync and status to toolbar via props

**Auto-sync on page load:**
- In CalendarView, trigger sync on mount via `useEffect(() => { handleSync(); }, [])` — but only if user is authenticated
- Need to know if user has Google auth. Pass `hasGoogleAuth: boolean` prop from calendar page (check session).
- In `app/calendar/page.tsx`: check `getServerSession(authOptions)` for `accessToken` existence, pass as prop.

**Rate limiting (from CONTEXT.md: "smart throttling"):**
- Client-side: track last sync time in state. If < 10 seconds since last sync and user clicks manual sync, show toast/message "Synced recently. Try again in X seconds." instead of firing request.
- Use a simple ref (`useRef<number>`) to track timestamp of last sync start.

**External events styling:**
- In CalendarView's `prismaEventToCalendarEvent`, external events will already have `editable: false` and `source: GOOGLE_CALENDAR`.
- In `eventPropGetter`: add styling for external events — slightly different opacity or a dashed border to visually distinguish from Almanac events. E.g., for `!event.editable && event.courseCode === 'GCAL'`: use `opacity: 0.7, borderStyle: 'dashed'`.
