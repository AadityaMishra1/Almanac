  <action>
Create `app/api/chat/route.ts` as a POST endpoint using Vercel AI SDK with Anthropic provider:

1. Import `createAnthropic` from `@ai-sdk/anthropic` and `streamText` from `ai`
2. Import all tool definitions from `@/lib/ai/tools`
3. Import `buildSystemPrompt` from `@/lib/ai/prompts`
4. Import `prisma` from `@/lib/db` to fetch current event context

The POST handler should:
1. Parse `{ messages }` from request JSON body
2. Fetch current events and courses from database for context injection:
   ```
   const events = await prisma.event.findMany({ include: { course: true }, orderBy: { date: 'asc' } })
   const courses = await prisma.course.findMany()
   ```
3. Build system prompt with `buildSystemPrompt({ events, courses, currentDate })`
4. Create Anthropic client: `createAnthropic({ apiKey: process.env.ANTHROPIC_API_KEY })`
5. Call `streamText` with:
   - model: `anthropic('claude-sonnet-4-5-20250929')` (Claude Sonnet 4.5)
   - system: the built system prompt
   - messages: from request
   - tools: all 5 tools from lib/ai/tools.ts
   - toolChoice: 'auto'
   - maxSteps: 5 (allow multi-step tool calling for complex queries)
6. Return `result.toDataStreamResponse()`

Add error handling:
- If ANTHROPIC_API_KEY is missing, return 500 with clear error message
- Wrap entire handler in try-catch, return 500 on unexpected errors

IMPORTANT: Validate that `process.env.ANTHROPIC_API_KEY` exists at the top of the handler. Do NOT check at module level (would crash at import time).
  </action>

Run `npx tsc --noEmit` to verify route compiles. Verify the file exports POST function. Check that it imports tools and prompts from lib/ai/.
