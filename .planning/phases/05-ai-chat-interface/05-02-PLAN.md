**lib/chat/persistence.ts:**
Create a localStorage-based persistence layer for chat messages (per CONTEXT.md: "Chat history persists like ChatGPT (users can scroll back) but each session starts with fresh conversation"):

1. Define a storage key constant: `const CHAT_STORAGE_KEY = 'almanac-chat-messages'`
2. Define a session key constant: `const CHAT_SESSION_KEY = 'almanac-chat-session'`

3. Export `loadChatMessages(): Message[]`
   - Read from `localStorage.getItem(CHAT_STORAGE_KEY)`
   - If found, parse JSON and return as `Message[]` (from 'ai' package)
   - If not found or invalid JSON, return empty array
   - Wrap in try-catch (localStorage can throw in private browsing)

4. Export `saveChatMessages(messages: Message[]): void`
   - Write `JSON.stringify(messages)` to `localStorage.setItem(CHAT_STORAGE_KEY)`
   - Only save messages with role 'user' or 'assistant' (skip tool invocations for storage efficiency -- tool results are ephemeral confirmation states)
   - Wrap in try-catch

5. Export `clearChatMessages(): void`
   - Remove the storage key from localStorage

6. Export `isNewSession(): boolean`
   - Uses `sessionStorage` (not localStorage) to track session lifespan
   - Check if `sessionStorage.getItem(CHAT_SESSION_KEY)` exists
   - If it does NOT exist: this is a new browser session. Set the key, clear old messages via `clearChatMessages()`, and return `true`
   - If it DOES exist: return `false` (existing session, keep messages)

This pattern ensures:
- Within a session (same tab/window): messages persist across page navigations and reloads
- New session (new tab, browser restart): starts fresh (per CONTEXT.md "each session starts with fresh conversation")
- localStorage for messages (survives page reload), sessionStorage for session detection (dies with tab)
