<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete AI Chat Interface (Phase 5) -- the final phase of Almanac v1. The system enables natural language event management through a floating chat widget on the calendar page. Claude interprets commands, proposes changes with diff previews, and executes after user confirmation. All operations are undoable via a version-control-style history panel.
  </what-built>
  <how-to-verify>
**Prerequisites:**
- ANTHROPIC_API_KEY must be set in .env.local
- At least 2-3 Almanac events should exist in the database (upload a syllabus if needed)
- Sign into Google for Calendar sync context

**CHAT-01: Modify events via natural language**
1. Navigate to /calendar
2. Click the chat bubble (bottom-right)
3. Type: "Move [event name] to next Friday"
4. Expected: Claude identifies the event, shows a diff preview (date: old -> new)
5. Click "Approve"
6. Expected: Event date updates in calendar, calendar refreshes

**CHAT-02: Bulk operations**
7. Type: "Delete all readings" (or another type with multiple events)
8. Expected: Claude shows a list with checkboxes, all pre-selected
9. Uncheck one event, then click "Delete Selected"
10. Expected: Selected events deleted, unchecked event remains

**CHAT-03: Create events via chat**
11. Type: "Add a study session for [course] on Wednesday at 3pm"
12. Expected: Claude shows a preview of the proposed event
13. Click "Approve"
14. Expected: New event appears on calendar

**CHAT-04: AI has read access to Google Calendar**
15. Type: "What events do I have this week?"
16. Expected: Claude lists both Almanac events AND Google Calendar events
17. Google Calendar events should be labeled as such (e.g., "from Google Calendar")

**CHAT-05: Only modifies Almanac events**
18. Type: "Delete [a Google Calendar event name]"
19. Expected: Claude responds that it cannot modify external Google Calendar events

**CHAT-06: Confirmation before changes**
20. Verify that steps 4, 8, 12 all showed confirmation dialogs before executing
21. Verify conflict warnings appear if moving an event to an overlapping time slot

**CHAT-07: Undo/revert**
22. Click the "History" tab in the chat widget
23. Expected: List of recent operations with timestamps
24. Click "Undo" on the most recent modify operation
25. Expected: Event reverts to its original date, calendar refreshes
26. Click "Undo" on a create operation
27. Expected: Created event disappears
28. Verify the undone item shows as grayed out in history

**UI/UX checks:**
29. Chat widget: collapsed is clean icon only, expanded is ~80% screen
30. Backdrop blur on calendar when chat is open
31. Mobile: open chat, verify near-full-screen and usable
32. Chat messages stream in (not appear all at once)
33. Empty state shows helpful prompt suggestions
34. Stop button halts streaming response

**Edge cases:**
35. Type an ambiguous command like "move the exam" (with multiple exams)
36. Expected: Claude asks a clarifying question
37. Type gibberish and verify Claude responds helpfully (not crash)
