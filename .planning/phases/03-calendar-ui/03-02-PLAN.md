       - Tailwind styling: bg-white, rounded-lg, shadow-lg, max-w-lg, p-6, animate-in/fade-in for smooth open

    2. Create `components/calendar/event-detail-modal.tsx`:
       - 'use client' directive
       - Import Dialog components from @/components/ui/dialog
       - Import updateEvent from @/app/server-actions/events
       - Import Button from @/components/ui/button
       - Import Input from @/components/ui/input

       Props:
       ```typescript
       interface EventDetailModalProps {
         event: CalendarEvent | null;
         open: boolean;
         onOpenChange: (open: boolean) => void;
         onEventUpdated: (updatedEvent: CalendarEvent) => void;
       }
       ```

       State:
       - isEditing (boolean, default false)
       - editValues: { title, date, time, type } initialized from event
       - isSaving (boolean, for loading state)
       - error (string | null)

       View Mode (isEditing = false):
       - Show event title in DialogTitle
       - Display fields as read-only text:
         - Date: formatted with date-fns format() ("EEEE, MMMM d, yyyy")
         - Time: formatted ("h:mm a") or "All day"
         - Type: capitalized with colored badge
         - Course: course name + code
         - Description: if present
       - Show course color dot next to course name
       - "Edit" button (only if event.editable is true) switches to edit mode
       - "Close" button via DialogClose

       Edit Mode (isEditing = true):
       - Title: text input pre-filled with current title
       - Date: native date input (type="date") with value in YYYY-MM-DD format
       - Time: native time input (type="time") with value in HH:MM format, or empty for all-day
         - Include a checkbox "All day event" that clears/shows time input
       - Type: select dropdown with options: exam, assignment, quiz, reading, lecture, lab, other
       - "Save" button: calls updateEvent server action with event.id and changed fields
         - On success: call onEventUpdated with updated data, switch back to view mode
         - On error: show error message, stay in edit mode
       - "Cancel" button: reset editValues to original, switch back to view mode
       - Show loading spinner on Save button while isSaving is true

    3. Wire modal into `components/calendar/calendar-view.tsx`:
       - Import EventDetailModal
       - Add selectedEvent state (already added in Task 1)
       - Render EventDetailModal below Calendar:
         ```tsx
         <EventDetailModal
           event={selectedEvent}
           open={!!selectedEvent}
           onOpenChange={(open) => !open && setSelectedEvent(null)}

         ```
       - handleEventUpdated callback:
         - Update the event in the local events array (optimistic update)
         - Close the modal by setting selectedEvent to null
         - The page will refetch on next navigation, but optimistic update keeps UI responsive
