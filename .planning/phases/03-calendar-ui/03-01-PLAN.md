    2. Create `lib/calendar/localizer.ts`:
       - Import dateFnsLocalizer from react-big-calendar
       - Import format, parse, startOfWeek, getDay from date-fns
       - Import enUS locale from date-fns/locale
       - Export singleton `localizer` instance
       - This is a simple config file, ~15 lines

    3. Create `lib/calendar/event-colors.ts`:
       - Define COURSE_PALETTE array of 10 distinct hex colors:
         '#3b82f6' (blue), '#ef4444' (red), '#10b981' (emerald), '#f59e0b' (amber),
         '#8b5cf6' (violet), '#ec4899' (pink), '#06b6d4' (cyan), '#f97316' (orange),
         '#14b8a6' (teal), '#6366f1' (indigo)
       - Export `getCourseColor(courseCode: string, explicitColor?: string | null): string`
         - If explicitColor is truthy, return it
         - Otherwise, compute deterministic hash from courseCode string
         - Return COURSE_PALETTE[Math.abs(hash) % COURSE_PALETTE.length]
       - Hash: simple char code accumulator `hash = ((hash << 5) - hash + charCode) | 0`

    4. Create `lib/calendar/ncsu-academic-calendar.ts`:
       - Export AcademicDate interface: { title: string; start: Date; end: Date; type: 'break' | 'finals' | 'holiday' | 'semester-start' | 'semester-end' }
       - Export SPRING_2026 array of AcademicDate objects (verified from NCSU calendar):
         - Spring Semester Begins: Jan 12
         - MLK Day: Jan 19
         - Wellness Day: Feb 17
         - Spring Break: Mar 16-21
         - Last Day of Classes: Apr 28
         - Reading Day: Apr 29
         - Final Examinations: Apr 30 - May 7
       - Export FALL_2025 array similarly
       - Export helper `getAcademicDatesForSemester(semester: string): AcademicDate[]` that returns matching array based on semester string (e.g., "Spring 2026" -> SPRING_2026)
       - For end dates, use the day AFTER the last day (exclusive end for RBC)

    5. Create `lib/calendar/conflict-detection.ts`:
       - Export TimeSlot interface: { eventId: string; start: Date; end: Date }
       - Export `findConflicts(events: TimeSlot[]): Set<string>` function
         - Sort events by start time
         - For each pair (i, j) where j > i: if sorted[j].start < sorted[i].end, both are conflicting
         - Break inner loop when sorted[j].start >= sorted[i].end (optimization since sorted)
         - Return Set of conflicting event IDs
       - Only consider timed events (not all-day) for conflicts
  </action>

       ```typescript
         courseCode: string;
         courseColor: string;
         courseName: string;
         description?: string;
         editable: boolean;
       }
       ```

       Define adapter function `prismaEventToCalendarEvent(event)`:
       - Takes Prisma Event (with course relation) and returns CalendarEvent
       - Parse date string "YYYY-MM-DD" using explicit year/month/day (NOT new Date("YYYY-MM-DD") which causes timezone issues)
       - If event.time exists: parse "HH:MM", create start Date with time, end = start + 1 hour, allDay = false
       - If no time: start = midnight of date, end = midnight of next day, allDay = true
       - Set courseColor via getCourseColor(event.course.code, event.course.color)
       - CRITICAL: Use `new Date(year, month - 1, day)` pattern (month is 0-indexed) to avoid timezone issues
